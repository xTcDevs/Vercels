# Zaga

Website for **Zaga**, a fashion house: designer, tailor and manufacturer.
Ready-to-wear shop, bespoke tailoring and manufacturing for other brands.

Static site, no build step. It deploys on Vercel as is (framework preset: **Other**,
no build command, output directory = repo root).

## Structure

```
index.html            the page
css/style.css         styles (--accent = the gold colour)
js/config.js          site settings: WhatsApp number
js/products.js        product list (generated by tools/render.py)
js/shop.js            shop: category tabs, colour swatches, quick view, ordering
js/main.js            contact form
assets/products/      every product in 10 colours (<product>-<colour>.webp)
assets/               logo files, favicon
tools/                scripts that build the product images from tools/photos/
```

## Shop

14 products in 10 categories (T-Shirts, Sleeveless, Long Sleeves, Polos, Hoodies,
Trousers, Shorts, Socks, Headwear, Bags), each in 10 colours: Black, Charcoal,
Stone, White, Sand, Brown, Burgundy, Olive, Forest, Navy.

Photographed colours show the real photo. Every other colour is a recolour of
that photo (folds, knit and monogram kept, logo flipped white/black for contrast,
zips and buckles untouched) and carries a small "Preview" badge.

A customer picks a colour and size, then "Order on WhatsApp" opens a chat with:
*"Hi Zaga, I'd like to order the Crest Hoodie in Burgundy, size L."*
With no number set, the order is copied into the contact form instead.

## Before going live

- `js/config.js`: set `whatsapp` (digits only, e.g. `2348012345678`).
- Prices: replace `[PRICE]` in `js/shop.js`, or add `"price"` per product (see below).
- `index.html`: replace the remaining `[PLACEHOLDERS]` (phone, Instagram handle,
  address, city, turnaround, minimum order, founder name, year, brand story) and
  point the Contact links at `https://wa.me/<number>` / `https://instagram.com/<handle>`.

## Adding or changing products

Product photos live in `tools/photos/` named `<item>-<colour>.jpg`
(e.g. `tee-black.jpg`). Products, categories, details and the colour palette are
defined at the top of `tools/render.py`.

```bash
pip install "rembg[cpu]" scikit-image scipy pillow   # once
python tools/segment.py      # cut each garment out of its background
python tools/logo_masks.py   # find logos and metal hardware
python tools/render.py       # render every colour + regenerate js/products.js
python tools/smoke_check.py  # optional: browser check (needs playwright)
```

Run them from the repo root. Masks are written to `tools/masks/` (git-ignored).

To give each product its own price, add `"price": "₦25,000"` to its entry in
`tools/render.py`, pass it into the catalogue, and show `p.price` in `js/shop.js`
in place of the `[PRICE]` text.
